# Ahamedh Farajeen Portfolio

Personal portfolio for A F Ahamedh Farajeen, a Software Engineering undergraduate at SLIIT. The site presents profile information, selected projects, project detail pages, resume download, and a simple contact form.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- CSS Modules
- Framer Motion

## Pages

- `/` - Home
- `/projects` - Featured projects
- `/projects/ecommerce` - MERN E-Commerce Platform
- `/projects/lms` - Learning Management System
- `/projects/starvote` - StarVote Reality Voting System
- `/about` - About
- `/contact` - Contact

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Scripts

```bash
npm run dev
npm run build
npm start
npm run lint
```

## Project Data

Project content is managed in [src/data/projects.ts](src/data/projects.ts). Static assets are stored in `public/`, including the resume, about photo, and project thumbnails.
